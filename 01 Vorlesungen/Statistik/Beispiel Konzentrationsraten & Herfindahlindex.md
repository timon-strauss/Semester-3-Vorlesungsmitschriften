Bsp: Markt mit 6 Us => Marktanteile: 30%,25%,20%,15%,8%,2%

**Konzentrationsraten**:

$CR_1 = 30$ => Marktanteile des größten
$CR_3 = 75$ => Summe der Marktanteile der größten 3
$CR_5 = 98$ => Summe der Marktanteile der größten 5

**Hefindahlindex**:

$H = 30^2 + 25^2 + 20^2 + 15^2 + 8^2 +2^2 = 2.218$

=> Je höher der Wert, desto konzentrierter auf einem Unternehmen sind die Marktanteile
Maximaler Herfindahlindex => 10.000, sobald ein Unternehmen 100% marktanteile hat
