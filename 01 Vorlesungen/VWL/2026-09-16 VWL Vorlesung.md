# Kapitel 4 Angebotstheorie

**Angebotsfunktion**: Angebot in Abhängigkeit vom Preis

**Vorgehen**:
1. Wieviel kann ich produzieren?
2. Wie kann ich am günstigsten produzieren?
3. Wieviel kann ich zu welchem Preis anbieten?

## Produktionsfunktion

Produktion muss sich anpassen an Umweltbedingungen => Wieviel kann ich mit meinen Produktionsfaktoren produzieren?
$q_x = f(v_1, ... , v_n)$

**Minimalkostenfunktion**: Wie kombiniere ich meine Produktionsfaktoren am günstigsten für einen gewissen output => Grundlage für Faktorvariation

**proportionale Faktorvariation**: Man kann jeden Produktionsfaktor gleichermaßen erhöhen, um den output zu steigern => nur langfristig relevant
**partielle Faktorvariation**: Einschränkung der kurzfristigen erhöhung oder Aufteilbarkeit einiger Faktoren => Ich kann nur ein paar von meinen Produktionsfaktoren erhöhen

## Kostenfunktion

**Betriebsminimum**: Minimum der variablen stückkosten => hier sind die Stückkosten ohne Fixkosten am günstigsten
**betriebsoptimum**: Minimum der stückkosten => Einbezug der Fixkosten

### Beispiel KstFkt
$K$: Kosten
$q_x$: Output

$$K = 12q_x - 2q_x^2 + \frac{q_x^3}{3} + 100$$
$$K´ = 12 - 4q_x + q_x^2$$
$$K_f = 100$$
$$K_v = 12q_x - 2q_x^2 + \frac{q_x^3}{3}$$

$k$: Stückkosten
$$k = 12 - 2q_x + \frac{q_x^2}{3} + \frac{100}{q_x}$$
$$k_f = \frac{100}{q_x}$$
$$k_v = 12 - 2q_x + \frac{q_x^2}{3}$$

## Preiselastizität des Angebots

**Analog** zu Preiselastizität der Nachfrage

$$A_x = q_x = -5 + 4p_x$$
(Für $p_x >= 1,25$)

$$p_x = 5 => A_x = 15$$

$$E = 4 · \frac{5}{15} = 1,33$$

Wenn $p_x + 1\%$, dann $A_x + 1,33\%$
