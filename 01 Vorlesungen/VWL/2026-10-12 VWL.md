# Kapitel 5

**homogenes Polypol**: Standardannahme für Märkte => viele Nachfrager, viele Anbieter
**natürliches Monopol**: Gutes Monopol

**Konsumentenrente**: Nachfrager hätten mehr bezahlen können
**Produzentenrente**: Anbieter hätten billiger verkaufen können

**Gesamtwirtschaftlicher Wohlfahrtsgewinn**: Konsumentenrente + Produzentenrente

- zusätzliche Anbieter durch Globalisierung => *Angebot steigt, Rechtsverschiebung*
- zusätzliche Nachfrager durch Globalisierung => *Nachfrage steigt, Rechtsverschiebung*
- allgemeine Lohnerhöhung in der Volkswirtschaft => *Angebot sinkt, Linksverschiebung; Nachfrage steigt, Rechtsverschiebung*
- starke Rohstoffpreiserhöhung/Erhöhung der Materialkosten => *Angebot sinkt, Linksverschiebung*
- Wegfall wichtiger Anbieter durch Krieg/Krisen => *Angebot sinkt, Linksverschiebung*
- Entwicklung eines preisgünstigen Substitutionsprodukts => *Nachfrage sinkt, Linksverschiebung*
- starker Preisanstieg bei Komplementärprodukten => *Nachfrage sinkt, Linksverschiebung*
- Einführung/Erhöhung einer produktbezogenen Steuer => *Angebot sinkt, Linksverschiebung*
- Produkt ist nicht mehr „in” => *Nachfrage sinkt, Linksverschiebung*
- Nachfrager erwarten in Zukunft starke Preiserhöhungen => *Nachfrage steigt (heute), Rechtsverschiebung*

Funktion basiert auf 2 Vorraussetzungen:
- Wettbewerb muss vorliegen
- Preise müssen flexibel sein, keine Einschränkungen

**Höchstpreis**: Preis darf nicht überschreiten
- Unter Marktgleichgewicht => Nachfrageüberhang: Verteilungsmechanismus funktioniert nicht mehr
- Über Marktgleichgewicht, kein Sinn, da Preis eh unter dem Höchstpreis liegt

**Folge von Höchstpreisen:
- Bildung von Schwarzmärkten

**Maßnahmen**: 
- Mindestproduktion erheben
- Betrieb verstaatlichen
- Subventionierung

**Mindestpreise**: Preis darf nicht niedriger sein
- Über Marktgleichgewicht => Angebotsüberhang
- Unter Marktgleichgewicht: kein Sinn

**Bei Monopol**:
- Höchstpreise sinnvoll
- Wettbewerbsbildung besser

**Bei Externen Kosten**: zb Umweltpolitik
- Mindestpreise sinnvoll
- Umweltpolitische maßnahmen besser

**pareto-Optimum**: Man kann nicht beide seiten besser machen, man mindert immer eine

 **Cournotscher Punkt**: Punkt an dem Monopolist eine Menge für einen Preis optimal verkauft

## Vergleich Polypol zu Monopol
**Annahme**: annähernd gleiche Kostenstruktur Monopol/Polypol

KRp => A + B + D
PRp => C + E
=> Gesamtwirtschaftliche Wohlfahrt => A + B + C + D + E

KRm => A
PRp => B + C
=> Gesamtwirtschaftliche Wohlfahrt => A + B + C

Monopolist kriegt höhere Produzentenrente

=> Im monopol ist die Gesamtwirtschaftliche Wohlfahrt geringer
