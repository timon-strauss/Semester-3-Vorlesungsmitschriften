# Definition
**Was ist OR**: 
- Optimierungen => welches Ergebnis ist das Optimalste
- Variablen so bestimmen, dass das Ziel bestmöglichst erreicht wird
- Verfahrenstechnik lernen => Ziel des Moduls

# Lineare Gleichungssysteme
- Lineare Gleichungssysteme sind essenzielle Grundlage
- Eindeutige Lösungen: Entweder keine, eine oder unendliche Menge an Lösungen
- pivot verfahren, gauß verfahren

# Mathematische Formulierung von Problemen
- **Variablen**: bsp. wie viele Mitarbeiter, wie viele Maschinen => Größen über die wir Entscheidungen treffen können. Millionen Variablen in der Praxis => Hier eher 3-5 variablen
- **Zielfunktion**: bsp. Gewinnmaximierung => Zielwert in Abhängigkeit der Variablen
- **nebenbedingungen**: nummeriert 1-n => Einschränkungen -> Variablen intervall, bsp Budget, Ressourcen, kein Einfluss auf Nebenbedingungen

# Modellierung
Modellierung heißt: 
Problem übertragen ins theoretische => Lösung erarbeiten => Lösung auf Praxis übertragen

Beispiel: Vorlesungsplanung
**Variablen**: Zeitplanung der Vorlesungen, Raumbelegung

# Lineare Optimierungsprobleme
Linear ist sobald: die Zielfunktionen und Nebenbedingungen durch eine lineare Funktion beschrieben werden können
