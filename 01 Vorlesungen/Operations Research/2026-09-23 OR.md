# Lineare Optimierung
**Wichtig**: Pivot Tabelle erst aufstellen, sobald eine zulässige Ecke gefunden wurde
Es lässt sich über die Tabelle nicht herausfinden, ob ein punkt zulässig ist

**Basisvariablen**: Variablen die ich bestimmen muss, um zu schauen ob der Punkt zulässig ist
**Nicht Basisvariablen**: Variablen die man auf 0 setzt

## Klausuraufgabe Lineare Optimierung
Aufgabenstellung lesen!!!

**Lineares Optimierungsproblem
- Startpunkt gegeben => Transformieren
- Startpunkt ist unzulässig => nächsten zulässigen finden
- Transferaufgaben für besser als 1.5

**Dualismus**
- Zu einem Minimierungsproblem ein Maximierungsproblem formulieren

## Sensitivitätsanalyse
**Frage**: Was sind meine limitierenden Faktoren => welche Rahmenbedingungen schränken mich ein

**knappe ressourcen**: Rahmenbedingungen, welche mich begrenzen => maximal ausgereizt => Schlupfvariable = 0
An der Zielfunktion kann man knappe Ressourcen ablesen

**reichliche ressourcen**: Rahmenbedingungen, welche noch ausreizbar sind => Schlupfvariable > 0

**Schattenpreise**: Koeffizienten der knappen Ressourcen in der Zielfunktion

## Sonderfälle

### Es gibt keine zulässige Lösung
**Fall 2D**: keine Fläche einzeichenbar
**Fall Mehrdimensional**: Bedingungen schließen sich gegenseitig aus => kein lösungsgebiet

**Erkenntnis**: In der Pivot Tabelle
- Kein Startpunkt bestimmbar
- Pivot Tabelle wird gar nicht aufgestellt

### Die optimale Lösung ist nicht eindeutig
**Fall 2D**: Zielfunktion liegt auf einer Bedingung => Steigung der Zielfunktion = Steigung einer Bedingung
**Fall Mehrdimensional**: Die Zielfunktion liegt auf einer Facette (= mehrdimensionale Seite des Polyeders) → die Zielfunktionsgerade/-ebene ist parallel zu einer bindenden Restriktion (gleiche Steigung/Gradient)

**Erkenntnis**: In der Pivot Tabelle
- Punkt kann weiter transformiert werden
- Nächste Transformation hat denselben Zielwert
- => Beide punkte sind Optimum und jeder Wert dazwischen auf der Gerade ebenso

### Es gibt kein Optimum
**Fall 2D**: Fläche ist nach außen offen
- Maximum => nach außen offene Bedingungen
**Fall Mehrdimensional**: Bedingungen schließen keinen Bereich ein

**Erkenntnis**: In der Pivot Tabelle
- Optimierung möglich => Koeffizienten sind negativ in der Tabelle
- Kein weiterer Eckpunkt im Lösungsgebiet => Quotient Q liefert keinen zulässigen Wert
- => Keine weiteren Punkte haben einen höheren Zielwert, jedoch wäre eine Optimierung möglich

### Entartung: 3 Nebenbedingungen schneiden sich in einem Punkt
**Fall 2D**: 3 Bedingungen schneiden sich in einem Punkt 
**Fall Mehrdimensional**: mehr Restriktionen sind aktiv als Variablen vorhanden sind

**Erkenntnis**: In der Pivot Tabelle
- Minimalquotient Q = 0 für eine Zeile
- Q = 0 => Ich bewege mich nicht weiter
- Bei Transformation über diese Zeile verändert sich der Zielwert nicht

## Dualität

Für jedes Maximierungsproblem existiert ein Minimieriungsproblem
**Dafür gilt**: Minimumsoptimum = Maximumsoptimum

**Fall**: Rahmenbedingungen haben gemischte ungleichungen also > und <
- Fall liegt außerhalb der Standartform
- Standartform enforcen => beide seiten mal -1 kippt das kleiner/größer zeichen
