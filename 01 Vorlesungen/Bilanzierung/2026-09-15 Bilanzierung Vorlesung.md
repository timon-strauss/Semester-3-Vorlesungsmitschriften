# Exkurs FiBu Vorbereitung Externes Rechnungswesen

**Rückstellung**: Passiva: Schuld => Unsicherheit über Höhe oder Grund
- Bsp. Gewährleistung: Kunde kann mit Mängel zurück kommen und Reparatur fordern
- => Geld zurücklegen, damit man den Kunden verpflegen kann, daher Schuld

**Aktivtausch**: Bsp. Barbezahlung einer Forderung => Soll an haben => Kasse an Forderung
- Bilanz bleibt gleich 

**Passivtausch**: Bsp. Kunde will Schadensersatz => Rückstellung an Verb.
- Bilanz bleibt gleich 

**Aktiv-Passiv-Mehrung**: Kauf einer Maschine auf Ziel => Maschinen an Verb
- Bilanz ist höher

**Aktiv-Passiv-Minderung**: Begleichen einer Verbindlichkeit durch Barzahlung => verb an bar
- Bilanz ist niedriger

**Erfolgsneutrale Geschäftsfälle**: Geschäftsfall verändert den Gewinn nicht => EK bleibt gleich
- Geschäftsfälle berühren nur die Bilanz

**Erfolgswirksame Geschäftsfälle**: Geschäftsfall verändert den Gewinn => EK verändert sich

**GuV**: darin gehen die Aufwands- und Ertragskonten
- Erfolgskonten
- Beeinflussen das Eigenkapital

# Kapitel 1 Jahresabschluss Grund & Funktionen

**Inventar**: listet Bestand auf
- Unterschied zur Bilanz: zeigt mehr Detail => genaue Art, Menge, Wert; Bilanz zeigt nur Wert
- Auch Auflistung der Schulden, zb Kredite

**Jahresabschluss Definition**: Herausgabe der Bilanz und GuV
- Bei Kapitalgesellschaften: Ergänzung Anhang

**Anhang**: Erläuterung des Inventars und Bilanzierung

**Gesetzliche Grundlagen**:
- §238 HGB Verpflichtet Unternehmen zur Buchhaltung => externes Rechnungswesen
- §240 HGB Verpflichet Unternehmen zum Inventar => Inventur durchführung
- §242 HGB Verpflichtung zum Jahresabschluss => veröffentlichung der Bilanz und GuV
- §§246 ff. HGB Pflicht, Wahlrecht, Verbot => Muss ich, darf ich oder ist es Verboten etwas in die Bilanz aufgenommen werden
- §§252 ff. HGB Bewertung der Positionen => Für wieviel darf ich meine Assets/Schulden bewerten
- §266 HGB Legt das Schema und Reihenfolge meiner Bilanz fest

=> **Wichtig**: Wortwahl => Ich **darf** oder ich **muss** etwas in die Bilanzierung aufnehmen

**Anlagevermögen**: Alles was dauerhaft in Unternehmen genutzt wird
**Umlaufvermögen**: Alles was kurzfristig im Unternehmen ist

**Aktiv-seitig**: Je schneller ich etwas verkaufen kann, desto weiter unten in der Bilanz
**Passiva-seitig**: Je schneller ich etwas zurückzahlen muss, desto weiter unten in der Bilanz

**Reinvermögen** = Eigenkapital

**Periodenerfolg**: Gewinn u. Verlust einer Periode
- EndEK - AnfangsEK
- Einbezug des Unternehmerlohns (bei Personengesellschaft)=> kein Gehalt, da man keinen Vertrag mit sich selber machen kann
- => Entnahmen und Einlagen 
- Privateinlage und Privatentnahme Konten werden beim abschluss ins EK Konto gebucht
- => Verändert nicht den Gewinn, beeinflusst nur das EK

**Totalerfolg**: Summe aller Periodenerfolge über die Lebensdauer eines Unternehmens
- Periodenerfolge sind durch das Wahlrecht beeinflussbar
- Totalerfolg Bleibt gleich, egal wie ich meine Periodenerfolge wähle
- Bsp. Abschreibung: Wahl auf Linear oder Degressiv beeinfluss Periodenerfolge, in Summe wird jedoch immer gleich viel abgeschrieben
- Bsp. §1 S. 18 - 21

## Gewinnanspruchsermittlung

**Ausschüttungsbemessungsfunktion**: Nur wenn ich einen Gewinn vorzuweisen habe, kann ich ausschütten
- Gebunden an Periodenerfolg
- Falls Gewinnkontingent besteht => Periodenfremde Ausschüttung möglich
- Ziel: Weniger Risiko für Investoren, dass die Unternehmer nicht bei Verlust trotzdem geld rausziehen
- Gläubiger-Eigner-Konflikt: Wer kriegt das Geld zuerst? => Gläubiger hat Vorrang
- Eigner-Manager-Konflikt: Unterschiedliche Interessen => Principal Agent Theorie

**Gläubiger-Eigner-Konflikt**:
- Keine Auschüttung von Fremdkapital
- Keine Auschüttung von Liquidationserlösen
- Eigenkapital ist Verlustpuffer

**Eigner-Manager-Konflikt**:
- Als kleiner Investor habe ich mehr risikobereitschaft als jemand dessen Arbeitsplatz vom Unternehmen abhängt
- Manager holt Firmenwagen => Gewinnreduzierung, nicht gut für Investoren

**Satzung**: Konkrete Regeln zur Ausschüttungshöhe des Gewinns

Auschüttungen abhängig von der Mehrung des Reinvermögens, nicht vom Zahlungsüberschuss

**Thessaurierung**: Teil des Gewinns bleibt im Unternehmen und wird weiterverwendet

**Infomationsinteressen**:
- Entscheidungsrelevanz => Unterstützt Entscheidungen
- Finanzplan => Vorplanungen der Ausschüttungen und Tilgungen

**Kapitalwert**: Was ist mein Geld theoretisch in X Jahren Wert

**Stille Reserver**: Differenz zwischen Buchwert und Marktwert
- Im Beispiel S. 39 => 13.000 Marktwert, 10.000 Buchwert => 3.000 Stille Reserve

=> An der Bilanz lässt sich nicht ablesen, wie viel ein Unternehmen Wert ist! Keine Marktgerechten Werte sind einbezogen
