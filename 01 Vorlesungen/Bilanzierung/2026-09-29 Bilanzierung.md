**Folgebewertung**: Wie entwickeln sich die Anschaffungskosten im Zeitablauf weiter

**Anschaffungskosten**: §253 I satz 1 HGB
- _einzelnd_ zugeordnet => direkte zurechnung von _Einzelkosten_,keine Gemeinkosten => zb Gas sind keine Anschaffungskosten
- Nur zahlungswirksame Aufwendungen
- Nur einmalig Anfallende Aufwendungen

**anschaffungsnebenkosten**: zb Montagekosten
**anschaffungspreisminderung**: zb Rabatte, Skonto

**Geringwertiges Wirtschaftsgut GWG**: Ist es unter einer Preisuntergrenze von 800€, wird die Sache gedanklich vollständig abgeschrieben, ist also direkt Aufwand

**Herstellungskosten**: §255 Abs 2 HGB 
- Aufwendungen durch verbrauch von Güter oder Inanspruchnahme von Diensten
- Es müssen tatsächlich entstandenen Kosten sein
- Es müssen notwendige Kosten sein

**Herstellungskostenarten**:
- Pflicht => Materialgemeinkosten, Fertigungsgemeinkosten, Abschreibungen der Maschinen
- Wahlrecht => Verwaltungsgemeinkosten
- Verbot => Vertriebsgemeinkosten

**Finanzierungskosten**: Grundsätzlich nicht einbezogen in die Herstellungskosten
- Ausnahme: Sofern sie im Zeitraum liegen und zur herstellung verwendet werden

**Kosten der Unterbeschäftigung**: Ich darf nur von der Normalproduktion ausgehen und dementsprechend Kosten angeben

**Planmäßige Abschreibung**: $253 HGB
- Vermögensgegenstände
- zeitlich begrenzte nutzung => Grund & Boden ist zeitlich unbegrenzt
- Abschreiben von den Anschaffungs/Herstellungskosten

**Abschreibungsplan**:
- Ich muss über eine gewisse Dauer Planen abzuschreiben
- Nutzungsdauer: Finanzamt gibt Tabellen als Hilfe => Ich kann selbst abschreiben
- Restwertberücksichtigung: 
- Abschreibungsverlauf
- Stetigkeitsprinzip

**Abschreibungsverlauf**:
- linear => Restbuchwert/Nutzungsdauer
- Degressiv => Restbuchwert · Prozentwert
- Solange Degressiv abschreiben bis lineare Abschreibung > degressive Abschreibung
- Sonst könnte man 0 nicht erreichen
- leistungsabhängig => zb Auto anhand den gefahrenen Kilometern

**Außerplanmäßige Abschreibungen**:
- Wert mindert sich außerplanmäßig => Abschreibung
- Nutzungsdauerverkürzung => Abschreibung in höhe von der verpassten Abschreibungshöhe
- Nutzungsdauerverlängerungen müssen nicht ausgwiesen werden

# Bewertung des Umlaufvermögens

**Fiktive Annahme**: Der Wert eines Gutes wird nach den Anschaffungskosten beurteilt => Welche Kosten nehme ich für Restbestände? Alter oder aktueller Einkaufspreis pro menge

**2 Möglichkeiten**: §256 HGB Durchschnittsverfahren
- Lifo Verfahren => Unterstellung, dass zuletzt beschaffene Vorräte verbraucht werden => Stille Reserven
- Fifio Verfahren =>Unterstellung, dass zuerst beschaffene Vorräte verbraucht werden => Scheingewinne

**Lifo**: 
- Der Schlussbestand wurde vom Preis des Anfangs gekauft
- Bestandswert => Ursprungspreis * Menge => 100 * 10
- Verbrauchswert => Verrechnung der Einkäufe mit den Mengen je Quartal zum jeweiligen Preis => Schlussbestand wurde nicht verkauft und wird mit den Anfangspreisen verrechnet

**Fifo**
- Der Schlussbestand wurde vom Preis des Endes gekauft
- Bestandswert => Endpreis * Menge => 100 * 15
- Verbrauchswert => Verrechnung der Einkäufe mit den Mengen je Quartal zum jeweiligen Preis => Schlussbestand wurde nicht verkauft und wird mit den Endpreisen verrechnet

**permanentes Lifo**: Zwischenstandsberechnung der Reserven nach Quartal
**permanentes Fifo**: Identisch zum normalen Fifo verfahren

**Klausur**: Aufgabe 7 kommt mit anderen Werten

**Durchschnittsverfahren**: Durchschnittspreis bilden und entsprechend den Mengen verrechnen

**permanentes Durchschnittsverfahren**: Periodische Durchschnitte und Verrechnung

**Abschreibung bei NWP**: Wenn eine wertminderung stattfindet wird abgeschrieben

**NWP Anlagevermögen**:
- definition dauerhaft => Wertminderung besteht von Stichtag zu Aufstellung der Bilanz
- definition vorrübergehend => Wertminderung besteht nicht von Stichtag zu Aufstellung der Bilanz
- Grundsätzlich: dauerhaft => Abschreibungspflicht; vorrübergehend => Abschreibungsverbot
- Ausnahem: Finanzanlagen, vorrübergehend => Wahlrecht

**NWP Umlagevermögen**: Immer niedrigerer Wert

**Wertaufholungsgebot**: Wurde eine Sache abgeschrieben, hat aber eine Werterhöhung bekommen, muss eine zuschreibung bis zum Anschaffungswert getätigt werden
